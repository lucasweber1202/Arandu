# Financial Procurement

Fluxo: organização compradora → RFQ em rascunho → abertura → convite por ID de organização fornecedora → resposta por usuário do fornecedor → comparação factual → decisão humana → contrato com início, fim e antecedência de renovação. O fornecedor só responde a RFQ aberta para a qual sua organização foi convidada. A proposta contém termos JSON por categoria, valor e validade; a UI apresenta os termos informados sem eleger vencedor.

Não há transferências, cotação automática, aconselhamento, custódia nem execução de operações. A validade de termos e licença de fornecedor não são verificadas automaticamente. O contrato é um registro operacional de renovação, não geração ou assinatura de instrumento jurídico.
